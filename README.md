# DigitaHinos Trompete

Visualizador MIDI com trompete animado (Si♭ ou Dó) (3 pistões, tabela de digitação completa de Fá♯3 a Fá6 escrito, com as digitações alternativas em pistões pequenos): os pistões descem e a tubulação extra de cada um acende, com o harmônico, a pauta em clave de Sol e o compositor.

- Seletor Si♭ / Dó no canto do instrumento: em Si♭ a nota na pauta é a ESCRITA (um tom acima do som real); em Dó, escrita = som. O MIDI e o áudio usam sempre o som real.
- Compositor com exportação WAV, MIDI, JSON e partitura em PDF (clave de Sol, com o desenho dos pistões sob cada nota); projetos salvos no navegador, autosave e importação de MIDI.
- Publicação: suba os arquivos no GitHub Pages. A cada versão nova, mude `CACHE_NAME` em `sw.js`.
- Pistões: 1 = −2 semitons, 2 = −1, 3 = −3. Alcance (som real): Mi3 a Mi♭6 (notas fora dele são dobradas de oitava).
